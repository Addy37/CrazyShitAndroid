# CrazyShit Android

A personal Android WebView wrapper for `https://crazyshit.com/`.

## APK build

GitHub Actions builds a debug APK automatically whenever `main` changes.

On GitHub:

1. Open **Actions**
2. Open **Build Android APK**
3. Open the latest successful run
4. Download the **CrazyShit-APK** artifact
5. Extract the ZIP and install `CrazyShit.apk` on Android

The app includes fullscreen video support, downloads, file uploads, persistent cookies, Android back navigation, external-link handling, an error screen, and a one-time 18+ / graphic-content warning.

This project is intended for personal sideloading/testing.
