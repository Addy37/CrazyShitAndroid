# Contributing

Contributions should focus on the Android wrapper itself.

Good topics include:

- WebView compatibility
- Fullscreen video behavior
- Android navigation and gestures
- Downloads and file uploads
- Accessibility
- Error handling
- Build and release automation

Please do not upload or commit CrazyShit.com videos, images, user submissions, logos, or other website media to this repository.

## Bug reports

When reporting a bug, include:

- Android version
- Device model
- App version
- What you expected
- What happened
- Steps to reproduce

Do not post account passwords, cookies, signing keys, or private personal information.

## Pull requests

Keep changes focused and explain what problem they solve. GitHub Actions should pass before a change is merged.

## Website issues

Account, content, DMCA, moderation, or privacy problems on CrazyShit.com itself belong with the website's official support/contact channels, not this wrapper repository.
