# CrazyShit 2.11.0

- Applies the approved black-and-yellow visual concept to Home, search and creator galleries.
- Home has source filters for All, CrazyShit, EFukt and Fapzone, larger responsive cards, source labels and video menus.
- New installations default to the Cards layout. Existing view-style choices remain available under More.
- Search uses a full-width field, circular creator avatars, favorite stars and a Search all results action above the keyboard.
- Creator galleries have a profile header, a working favorite button and a two-column phone grid by default. Saved grid-size choices remain supported.
- Shared headers and the navigation pill use flat black and charcoal surfaces.
- Existing favorites, downloads, backups and playback features remain supported.

Install over your current stable app to retain saved data. Live content and availability depend on the source sites.
