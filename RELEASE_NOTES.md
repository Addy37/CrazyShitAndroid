# CrazyShit v2.8.4

CrazyShit 2.8.4 adds polished notifications for new videos and app updates.

## New video alerts

- Checks CrazyShit and EFukt for new uploads in the background
- Groups alerts cleanly when both sites add videos
- Uses branded icons, expandable text, and direct links to the matching latest feed
- Hides video titles by default for discreet notifications
- Lets you show titles when you want extra detail
- Establishes a quiet first baseline so installing the update does not report old videos as new
- Ignores unusually large feed changes instead of flooding the notification shade

## Notification settings

- Adds separate controls for CrazyShit and EFukt alerts
- Adds hourly, 3-hour, and 6-hour check options
- Adds a branded preview notification
- Explains notification access before Android requests permission
- Keeps background checks network-only and battery-aware

## App updates

- Sends a notification when a new stable app version is ready
- Opens the existing verified in-app updater when tapped
- Waits for you to approve the download and Android installation
- Removes automatic background APK downloads

## Compatibility

- Keeps the existing stable application ID and signing identity
- Installs directly over CrazyShit 2.8.3
- Keeps alerts optional and controllable through Android notification channels
